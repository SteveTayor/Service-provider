PROJECT OVERVIEW
===============
Bundlegram Mobile is a Flutter application built using the BolaFFU (Flutter Framework Universal) template, implementing clean architecture principles. The application includes authentication, marketplace, wallet, and agent systems.

TECHNICAL REQUIREMENTS
=====================
1. Architecture
   - Clean Architecture with distinct layers:
     * Core Layer (utilities, configs)
     * Data Layer (repositories, models)
     * Domain Layer (entities, use cases)
     * Presentation Layer (UI, state management)

2. Core Features
   - Authentication System
     * User registration
     * Login/Logout
     * Password recovery
     * Email verification
     * Profile management

   - Product Marketplace
     * Product listing
     * Search and filters
     * Product details
     * Shopping cart
     * Checkout process

   - Wallet System
     * Balance management
     * Transaction history
     * Payment processing
     * Fund transfers

   - Agent System
     * Agent profiles
     * Agent marketplace
     * Communication system
     * Rating system

3. Technical Stack
   - Flutter for cross-platform development
   - Riverpod with Notifier for state management
   - GoRouter for navigation
   - Dio for API integration
   - Hive for local storage
   - GetIt for dependency injection

FOLDER STRUCTURE
===============
1. Core Layer (lib/core/)
-------------------------
Purpose: Contains application-wide utilities and configurations
Required Components:
- config/
  * app_config.dart (Environment configurations)
  * theme.dart (App theming)
  * constants.dart (Global constants)
  * env.dart (Environment variables)

- extensions/
  * string_extensions.dart
  * context_extensions.dart
  * datetime_extensions.dart
  * widget_extensions.dart

- router/
  * app_router.dart (Route definitions)
  * route_guards.dart (Navigation guards)
  * route_constants.dart (Named routes)

- utils/
  * validators.dart (Input validation)
  * formatters.dart (Data formatting)
  * helpers.dart (Helper functions)
  * logger.dart (Logging utility)
