PROJECT OVERVIEW
===============
BolaFFU is a standardized Flutter project template that implements clean architecture principles with a focus on scalability, maintainability, and code organization.

3. Presentation Layer (lib/presentation/)
---------------------------------------
Purpose: Handles UI components and state management

Required Components:
- features/auth/
  * bloc/auth_bloc.dart:
    ```dart
    class AuthBloc extends Bloc<AuthEvent, AuthState> {
      final AuthRepository _authRepository;

      AuthBloc(this._authRepository) : super(AuthInitial()) {
        on<LoginRequested>(_onLoginRequested);
      }

      Future<void> _onLoginRequested(
        LoginRequested event,
        Emitter<AuthState> emit,
      ) async {
        emit(AuthLoading());
        try {
          final user = await _authRepository.login(
            event.email,
            event.password,
          );
          emit(AuthSuccess(user));
        } catch (e) {
          emit(AuthFailure(e.toString()));
        }
      }
    }
    ```

USAGE INSTRUCTIONS
=================
To use this template, call the following command in chat:

```
bolaffu generate [project_name] [output_path]
```

Example:
```
bolaffu generate my_app /path/to/project
```

This will:
1. Create the folder structure
2. Generate all template files with base implementations
3. Set up pubspec.yaml with required dependencies
4. Initialize git repository
5. Create README.md with project setup instructions

The generator will maintain all code properties and create a fully functional Flutter project structure following clean architecture principles.
